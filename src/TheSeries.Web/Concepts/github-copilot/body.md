## GitHub Copilot

**GitHub Copilot** is an AI coding assistant from GitHub and Microsoft. It started as
inline code completion and has grown into a full **agentic coding harness**:

- **Completions** — suggests code as you type.
- **Chat** — ask questions about your code, get explanations and fixes.
- **Agent mode** — give it a task and it plans, edits multiple files, runs terminal
  commands and tests, and iterates until the work is done — the same think-act-observe
  loop this app visualises.

Copilot runs inside editors like **VS Code**, Visual Studio and JetBrains IDEs, and can be
customised with instructions, prompt files and skills. It can use different underlying
models.

This sample app borrows Copilot's vocabulary — **harness**, **tools**, **skills**,
**personas** — to make the concepts concrete. Pick the **GitHub Copilot** theme to see the
diagram in Copilot's colours.
