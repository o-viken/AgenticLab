## Claude Code

**Claude Code** is Anthropic's agentic coding tool, powered by the Claude models. It runs
in your **terminal** (and integrates with editors) and works directly against your
repository:

- Reads and **searches** the codebase to build context.
- **Edits files** and makes multi-step changes.
- **Runs commands** — builds, tests, git — and reacts to the output.
- Follows project instructions and **skills** for repeatable workflows.

It's a clear example of the **agent = model + harness** idea: Claude supplies the
reasoning, and the Claude Code harness supplies the file, terminal and repo tools plus the
loop that drives them — the same shape as the **Coder** agent here.

Pick the **Claude Code** logo to select its representative harness while keeping the shared workbench colors.
