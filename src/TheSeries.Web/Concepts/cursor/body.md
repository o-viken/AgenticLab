## Cursor

**Cursor** is an **AI-first code editor** — a fork of VS Code built around AI assistance
rather than bolting it on. It indexes your project so the model has rich **codebase
awareness**, and its agent can plan and apply changes across many files.

- **Inline edits & completions** tuned to your code.
- **Chat** grounded in the whole repository.
- An **agent** that runs the plan → edit → run → review loop and proposes multi-file diffs.

Like the other tools here, Cursor is an **agentic coding harness**: it pairs an LLM with
editor, file and terminal tools and a loop — the concept this app makes visible.
