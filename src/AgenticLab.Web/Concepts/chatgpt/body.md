## ChatGPT

**ChatGPT** is OpenAI's widely used assistant, built on the GPT family of models. It began
as pure conversation and now includes agentic capabilities:

- **Chat** — answer questions, write and explain text or code.
- **Tools** — browse the web, run code, generate images, and call connected tools/APIs.
- **Agentic tasks** — break a goal into steps and carry them out across several turns.

OpenAI models are available to developers through the **OpenAI API** and **Azure OpenAI**.
This app supports both, with your own tools and harness, following
exactly the request → tool-call → result → response loop drawn in the diagram.

Pick the **ChatGPT** logo to select its representative harness while keeping the shared workbench colors.
