# Response style

These project conventions apply to every reply in this workspace:

- Begin every reply with a one-line **TL;DR:** summary of the answer.
- Use British English spelling (e.g. "colour", "organise", "behaviour").
- End every reply with the sign-off line on its own: `— Agentic Lab demo agent`.
