Core concepts

The agent harness

The harness is the application around a model. It supplies context, exposes tools and controls the execution loop.

A model proposes the next action. The harness executes that action and sends the result back.

In this exchange

  • The user asks a factual question.
  • The agent searches Wikipedia.
  • The tool result grounds the final answer.
